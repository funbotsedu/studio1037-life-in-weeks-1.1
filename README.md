# 4000 недель · Life in Weeks

Личный дневник Studio1037. Чтобы запустить приложение, откройте `index.html` в браузере. Для разработки можно запустить `python -m http.server 8000` в корне репозитория и открыть `http://localhost:8000`. Сборка и зависимости не нужны.

## Перенос дневника

1. Откройте v1.1 там, где видны ваши записи, и нажмите **Экспорт**. Сохраните файл JSON у себя.
2. Откройте v1.2 и выберите **Импорт из копии** при первом запуске или **Импорт** в верхней панели.
3. Выберите файл и проверьте количество добавляемых и пропускаемых недель перед подтверждением. Записи в занятых неделях не заменяются. Если даты рождения различаются, импорт отклоняется.
4. Откройте несколько перенесённых недель и проверьте текст и фотографии. Сохраните исходную копию.

Файл резервной копии может содержать личные данные. Не добавляйте его в Git. Дневники хранятся в браузере отдельно для каждого адреса сайта и профиля браузера. Синхронизации между устройствами нет. Регулярно сохраняйте резервную копию: очистка данных сайта удалит локальный дневник.

## Cloudflare Pages

Создайте отдельный Pages-проект с GitHub-интеграцией. Производственная ветка — `main`, preset — None, команда сборки пустая, папка публикации — корень репозитория (`.`). Сервер и облачное хранилище приложению не нужны.
